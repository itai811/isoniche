# Package index

## Analyse your data

Estimate niche breadth for one or many species, from long-format data.

- [`niche_breadth()`](https://itai811.github.io/isoniche/reference/niche_breadth.md)
  : Density-independent and density-dependent niche breadth
- [`summary(`*`<niche_breadth>`*`)`](https://itai811.github.io/isoniche/reference/summary.niche_breadth.md)
  [`print(`*`<summary.niche_breadth>`*`)`](https://itai811.github.io/isoniche/reference/summary.niche_breadth.md)
  : Summarise niche breadth results and their diagnostics
- [`plot(`*`<niche_breadth>`*`)`](https://itai811.github.io/isoniche/reference/plot.niche_breadth.md)
  : Plot niche breadth against abundance
- [`iai_curve()`](https://itai811.github.io/isoniche/reference/iai_curve.md)
  : Niche breadth as a function of total abundance
- [`plot(`*`<iai_curve>`*`)`](https://itai811.github.io/isoniche/reference/plot.iai_curve.md)
  : Plot niche breadth curves

## Prepare your data

- [`community_to_long()`](https://itai811.github.io/isoniche/reference/community_to_long.md)
  : Convert a community matrix to long format
- [`check_coverage()`](https://itai811.github.io/isoniche/reference/check_coverage.md)
  : Sampling coverage of each species and habitat
- [`group_sites()`](https://itai811.github.io/isoniche/reference/group_sites.md)
  : Group nearby sites into sampling units
- [`radius_sensitivity()`](https://itai811.github.io/isoniche/reference/radius_sensitivity.md)
  : Sensitivity of niche breadth to the grouping radius

## Isodars and lower-level tools

Fit isodars and compute niche breadth for one species.

- [`fit_isodars()`](https://itai811.github.io/isoniche/reference/fit_isodars.md)
  : Fit isodars
- [`iai()`](https://itai811.github.io/isoniche/reference/iai.md) :
  Isodar-adjusted inequality (IAI)
- [`isoderr()`](https://itai811.github.io/isoniche/reference/isoderr.md)
  : Bootstrap uncertainty of the isodar-adjusted inequality
- [`pairwise_niche()`](https://itai811.github.io/isoniche/reference/pairwise_niche.md)
  : Niche breadth indices from pairwise isodar parameters
